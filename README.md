# 🗼 역사 타워 레이스

초등 사회 5학년 2학기 1단원 「유적과 유물로 살펴본 옛 사람들의 생활」 복습 게임입니다.
구석기부터 고려까지 18층 탑을 오르며 층마다 문제를 풀고 유물 카드를 모읍니다.

- **플레이**: https://ggcrunch00.github.io/history-tower/
- 컴퓨터: WASD·↑↓ 이동, ←→ 방향 돌리기, 스페이스 점프, 마우스 끌기로 시점, Shift 시선 고정, 1·2·3 정답 고르기, R 체크포인트, M 소리
- 태블릿: 왼쪽 아래 조이스틱 이동, 점프 버튼 또는 오른쪽 화면 톡, 오른쪽 화면 끌기로 시점, 🔒 시선 고정, 문제 창 버튼으로 정답 고르기

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 게임 본체 |
| `questions.js` | 문제와 정답, 오답 보기 |
| `artifacts.js` | 유물 카드 18장 (설명·블록 모델) |
| `scenery.js` | 시대별 배경 섬 |
| `sound.js` | 배경음악·효과음 (직접 합성, 음원 파일 없음) |
| `lib/three.min.js` | three.js r159 (MIT 라이선스, `lib/three-LICENSE.txt`) |

인터넷 없이도 폴더째 내려받아 `index.html`을 열면 실행됩니다.
